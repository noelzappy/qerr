# Schibsted Grotesk (the Qerr wordmark)

The web app's own copy of the typeface of the Qerr wordmark, used only by the logo (`web/src/shell/QerrLogo.tsx`, loaded
in `web/src/index.css`). Posts never use it; the engine's fonts are in `packages/engine/design/fonts`.

- File: `schibsted-grotesk-v7-800-latin.woff2`, ExtraBold (800), normal, `latin` subset only, 25104 bytes.
- Source: https://fonts.googleapis.com/css2?family=Schibsted+Grotesk:wght@800&display=swap, file from fonts.gstatic.com
