# qerr logo

Colours: ink #1b1a18 · paper #f7f6f2 · accent #e0532f
Wordmark: Schibsted Grotesk ExtraBold (800), lowercase, tracking −0.055em
Mark: ring + square tail. The square's bottom edge sits on the wordmark baseline.

- svg/ — mark, lockups (light, reversed, mono), app icon, favicon.svg (adapts to dark mode)
- png/ — favicons 16/32/48, apple-touch-icon 180, app icons 192/512/1024, mark 1024, lockups 2000px wide (transparent and on light/dark)

Use the mono mark for watermarks on rendered posts.
Lockup SVGs embed the font; outline the text in a vector editor before sending to print.
